Модель песчаной кучи (Sandpile Cellular Automaton)

Компьютерная модель клеточного автомата, реализованная на Python с использованием библиотек NumPy и Matplotlib. Программа демонстрирует процесс самоорганизованной критичности (СОК) на примере классической модели песчаной кучи Бака–Танга–Визенфельда (BTW), позволяя исследовать лавинообразные процессы и анализировать их статистические характеристики.
1. Краткое описание модели

Модель песчаной кучи — это клеточный автомат, в котором каждая клетка решётки представляет участок поверхности, на который постепенно добавляется песок. Когда количество песчинок в клетке превышает порог, происходит «обвал», и песчинки перераспределяются по соседним клеткам, что может вызвать цепную реакцию — лавину.
Состояния клетки

Каждая клетка поля может находиться в одном из h+1 состояний, где h — порог обвала (обычно 4):

    0, 1, ..., h−1 — количество песчинок в устойчивой клетке;

    h — клетка неустойчива и готова к обвалу.

Правила перехода

На каждом такте состояние всех клеток обновляется синхронно:

    Добавление песчинки. В центральную клетку решётки добавляется одна песчинка.

    Релаксация (обвал). Процесс повторяется циклически, пока в системе есть неустойчивые клетки:

        все клетки с количеством песчинок >= h одновременно «обваливаются»: их значение уменьшается на h;

        каждый из 4-х соседей (окрестность фон Неймана) получает по одной песчинке;

        песчинки, вышедшие за границы решётки, считаются потерянными (фиксированные граничные условия).

Математическая модель

Пусть F — текущее состояние поля (матрица m × m, где F[i,j] ∈ {0, 1, ..., h}). Окрестность N — фон Неймана (4 соседа).

Правила перехода для одного подшага релаксации:

    определяется маска неустойчивых клеток: U(i,j) = F(i,j) >= h;

    F_new(i,j) = F(i,j) − h · U(i,j) + Σ U(i+di, j+dj), для (di, dj) ∈ N.

Этот процесс повторяется до тех пор, пока U не станет пустой. Один полный такт симуляции включает в себя добавление песчинки и последующую полную релаксацию системы.
Граничные условия

Используются фиксированные границы: клетки за пределами поля считаются «стоком», то есть песчинки, ушедшие за край, исчезают. Это реализуется программно путём игнорирования соседей, находящихся за границами массива, при подсчёте перераспределения. В коде также предусмотрен режим периодических границ (boundary='periodic'), при котором песчинки «заворачиваются» через np.roll.
Реализация на Python

Модель реализована в виде класса SandpileCA, который инкапсулирует состояние поля и логику его эволюции. Релаксация лавины происходит синхронно с использованием булевых масок NumPy, что обеспечивает высокую производительность.

Код метода relax() (фрагмент):
python

def relax(self):
    total_topplings = 0
    affected_cells = set()
    lost_grains = 0
    duration = 0

    while True:
        unstable = self.grid >= self.h
        if not unstable.any():
            break

        duration += 1
        unstable_idx = np.argwhere(unstable)
        total_topplings += len(unstable_idx)

        for i, j in unstable_idx:
            affected_cells.add((i, j))

        # --- Синхронный обвал ---
        delta = self._distribute(unstable)
        self.grid[unstable] -= self.h

        # Потери = сколько должны были отдать - сколько реально отдали
        if self.boundary == 'open':
            lost_grains += int(unstable.sum()) * self.h - int(delta.sum())

        self.grid += delta

    return total_topplings, len(affected_cells), duration, lost_grains

Здесь:

    unstable — булева маска клеток, готовых к обвалу;

    _distribute(...) — вспомогательный метод, который рассчитывает, сколько песчинок получит каждая клетка, и обрабатывает граничные условия;

    total_topplings, affected_cells, duration, lost_grains — метрики, собираемые для каждой лавины.

2. Возможности и ограничения
✅ Возможности

    Классическая модель BTW. Реализована каноническая модель песчаной кучи с порогом h = 4 и окрестностью фон Неймана.

    Синхронное обновление. Корректно реализован процесс релаксации, при котором все неустойчивые клетки обваливаются одновременно.

    Сбор подробной статистики. Для каждой лавины собираются её размер (число обвалов), площадь (число затронутых клеток), длительность (число подшагов релаксации) и количество потерянных песчинок.

    Визуализация. Программа строит графики распределения лавин по размерам и длительности в лог-лог масштабе, временной ряд размеров лавин, а также анимирует процесс эволюции поля.

    Гибкость. Параметры симуляции (размер поля, порог, количество шагов, тип границ) легко изменяются в основном блоке if __name__ == "__main__":.

    Два типа границ. Поддерживаются как открытые ('open'), так и периодические ('periodic') граничные условия.

⚠️ Ограничения

    Только 2D. Модель работает только на двумерной квадратной решётке.

    Фиксированная точка добавления. В базовой реализации песчинка всегда добавляется в центр поля.

    Синхронная релаксация. Хотя это и соответствует классической модели, это не единственный возможный способ реализации (существуют асинхронные версии).

    Ограниченный размер. Размер поля конечен, что влияет на максимальный размер лавин.

    Эффекты границ. При малом поле статистика может искажаться из-за конечного размера системы и потерь песчинок в сток.

3. Инструкция по запуску
Установка зависимостей

Откройте терминал в папке проекта и выполните:
bash

pip install -r requirements.txt

Запуск модели

Программа запускается из Jupyter Notebook. Просто выполните все ячейки по порядку.

В основной ячейке (if __name__ == "__main__":) можно настроить параметры:

    SIZE — размер поля (по умолчанию 100×100);

    STEPS — количество шагов симуляции (по умолчанию 30 000);

    THRESHOLD — порог обвала h (по умолчанию 4);

    BOUNDARY — тип границ: 'open' (песчинки теряются) или 'periodic' (песчинки переходят на другую сторону поля).

Что произойдёт

    В консоль будет выведен прогресс симуляции с интервалом в record_every шагов.

    По завершении симуляции будут построены графики:

        финальное состояние поля;

        распределение размеров лавин (log-log);

        распределение длительности лавин (log-log);

        временной ряд размеров лавин;

        график выхода системы на стационар (средняя высота).

    Будет сохранён GIF-файл sandpile_animation.gif с анимацией эволюции поля.

    В консоль будут выведены итоговые статистические данные и оценки показателей степенного закона.

Что наблюдать на графиках

🔵 Распределение размеров лавин (Рис. 1).
График в лог-лог масштабе. Прямая линия в широком диапазоне размеров указывает на степенной закон распределения. Наклон прямой (показатель степени τ_s) — ключевая характеристика самоорганизованной критичности.

🟢 Распределение длительности лавин (Рис. 2).
Аналогичный график для длительности лавин. Наклон (τ_d) также должен быть близок к теоретическим значениям.

🟡 Временной ряд размеров лавин (Рис. 3).
Демонстрирует перемежаемость: длительные периоды мелких лавин прерываются внезапными крупными «катастрофами». Это визуальное подтверждение СОК.

🟠 Динамика средней высоты поля (Рис. 4).
График показывает, как система из начального пустого состояния выходит на стационарный режим. Средняя высота поля стабилизируется около критического значения (~2.1 для h = 4), что является признаком достижения критического состояния.
